# DreamHome3D Design Reference

The new Designer screen was upgraded to follow the supplied DreamHome3D reference image: dark professional workspace, blue navigation, 3D/2D switcher, left design navigation, central 3D viewport, metrics bar, and right-side room properties/furniture controls.

Reference image is included at:
`client/public/reference/dreamhome3d-design-reference.png`

The reference is used as a visual design target; the actual application remains functional and renders its own Three.js/React Three Fiber scene rather than using the screenshot as the 3D canvas.
